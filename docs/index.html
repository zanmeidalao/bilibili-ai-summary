搭配AI总结助手的AI分析提示词分享页

把下面这些提示词复制到你的 AI（DeepSeek / ChatGPT 等），再用 B站字幕AI总结扩展一键把字幕发过去，即可得到结构化分析报告。

📝 支持 SRT / VTT / 纯文本字幕

🤝 有好的提示词？分享给大家

点击我要分享提示词按钮，在仓库里提交你的提示词（建议搭配 SRT 字幕）如：影视分析/学术分析/简要分析/时政新闻分析/等细分领域提示词。提交后由维护者审核，通过即展示在本页。

没有匹配的提示词，换个关键词试试～

📍 怎么用

1
复制提示词点卡片上的「复制全文」，把提示词贴进你的 AI 对话框。
2
打开 B站视频在视频页找到粉色圆形悬浮按钮（写着「字幕 / 复制」）。
3
发送字幕右键悬浮按钮 → 控制面板 → 选「分析提示词 / 发送到 AI」，字幕自动填入。
4
拿到报告AI 按提示词输出：速读、逻辑骨架、金句、事实核查与总评。
